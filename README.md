# FanCraft - Virtual Dating Content Creator

A web-based platform for K-pop fans to create virtual dating content with their favorite idols.

## 🌟 Features

### Content Creation Tools
- **Message Chat Templates** - Create realistic chat conversations
- **Lock Screen Notifications** - Design romantic lock screen alerts  
- **Instagram Story Posts** - Make shareable story content
- **Real-time Preview** - See changes instantly
- **Custom Elements** - Add photos, text, timestamps

### Series Management
- **Story Series** - Group content into episodic series
- **Timeline Management** - Organize content chronologically
- **D-day Counters** - Set special anniversary dates
- **Unique URLs** - Share series with custom links

### Social Features
- **Explore Feed** - Discover popular content
- **Anonymous Interactions** - Like and comment safely
- **Content Sharing** - Share to social platforms
- **Community Discovery** - Find trending series

### User Experience
- **Mobile-First Design** - Optimized for mobile devices
- **Hip & Modern UI** - K-pop inspired aesthetic
- **Offline Support** - Works without internet
- **Fast Performance** - Quick loading and interactions

## 🎯 Target Audience

**Primary Users:** K-pop fans aged 17-25 in English-speaking countries
- Familiar with K-pop fandom culture
- Enjoy creating and sharing content
- Active on social media platforms
- Want realistic virtual dating experiences

## 🚀 Quick Start

1. Open `index.html` in a modern web browser
2. Click "Start Creating" to begin
3. Choose a template (Message, Lock Screen, or Story)
4. Customize your content with text and images
5. Save and share your creation

## 🛠️ Technical Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Design System:** Based on KF_Calendar components
- **Fonts:** Pretendard (Korean-optimized)
- **Icons:** Font Awesome 6
- **Storage:** LocalStorage (demo mode)
- **PWA:** Service Worker for offline support

## 🎨 Design System

## 📖 Usage Guide

### Creating Content
1. **Choose Template** - Select from 3 available templates
2. **Customize Elements** - Edit text, images, and settings
3. **Preview Changes** - See real-time updates
4. **Save Content** - Store locally or export

### Managing Series
1. **Create Series** - Group related content
2. **Add Episodes** - Build story progressions
3. **Set Dates** - Track special moments
4. **Share Series** - Generate shareable links

### Exploring Community
1. **Browse Feed** - Discover popular content
2. **Filter Content** - Find specific types
3. **Interact Safely** - Like and comment anonymously
4. **Share Favorites** - Spread great content

## 🔒 Privacy & Safety

- **Anonymous Interaction** - No personal data required
- **Safe Sharing** - Content filtered for appropriateness
- **Local Storage** - Data stays on your device
- **No Account Required** - Use immediately without signup
